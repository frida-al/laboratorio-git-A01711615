`git init`: crea un repositorio local (solo en tu compu) para la trazabilidad de los archivos

`git clone`: crea una rama local de un repositorio preexistente remoto

`git add .`: agrega uno o varios archivos al área de preparación antes de hacer un commit y un push

`git commit -m`: agrega un mensaje y empaqueta los archivos que están en el área de preparación para que se suban al repo remoto en un solo paquetito (aunque sean varios archivos)

`git push`: empuja cambios locales al repo remoto

`git pull`: trae a tu compu los cambios que ya se encuentran en el repo remoto

`git log`: te muestra los últimos cambios en git

`git status`: te muestra si hay archivos sin guardar o con modificaciones y en qué área se encuentran

`git diff`: te muestra las diferencias entre un archivo guardado y un archivo recién editado

`git diff --staged`: te muestra las diferencias entre un archivo guardado y un archivo que ya está en el área de preparación

`git restore`: elimina los cambios de un archivo que solo guardaste pero no entró al área de preparación

`git restore --staged`: saca un archivo del área de preparación sin eliminar los cambios que hiciste
